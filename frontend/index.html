Why This Project

The Problem We're Solving

Honeybees pollinate approximately 75% of crops worldwide. Monitoring their activity is critical — but traditional methods are manual, slow, and error-prone.

🌍

Global Food Security

Nearly one-third of the world's food production depends on pollination. Honeybee population decline due to climate change, habitat destruction, and pesticide exposure poses serious risks to biodiversity and agriculture.

⏱️

Manual Monitoring Fails

Traditional hive monitoring relies on manual inspection — time-consuming, labour-intensive, and prone to human error. These limitations make it nearly impossible to detect early signs of colony stress or absconding reliably.

🤖

AI-Powered Solution

This project automates honeybee monitoring using YOLO-based deep learning. It processes video frames to accurately detect and count bees, then triggers real-time Telegram alerts when the count drops dangerously low.

Dataset & Training

How the Model Was Trained

A custom dataset was built from real-world YouTube honeybee footage and annotated using the Roboflow platform.

Data Collection

YouTube Hive Videos

High-quality honeybee videos were collected from YouTube, covering hive entrance activity, outdoor pollination scenes, different lighting environments, and varying bee densities. Frames were extracted using FFmpeg at regular intervals to simulate real-time monitoring conditions.

Hive Entrance Footage FFmpeg Frame Extraction Multiple Lighting Conditions
Annotation

Roboflow Platform

Each visible honeybee was manually annotated with bounding boxes using Roboflow's web interface. Multiple bees were labelled per image. The platform also handled dataset versioning, augmentation, and export in model-compatible formats for each architecture tested.

Manual Bounding Boxes Roboflow Annotation Single Class: Honeybee
Data Augmentation

Improving Generalisation

Augmentation techniques were applied within Roboflow before exporting datasets to increase diversity and improve model generalisation. All four models were trained on the same augmented dataset using identical hyperparameters to ensure a fair and consistent architectural comparison.

Rotation & Scaling Brightness Variation 80% Train / 20% Test Split
Post-Processing

Custom Deduplication Filter

After YOLO inference, a center-distance based deduplication algorithm is applied. Bounding boxes whose centers fall within 40px of a higher-confidence detection are suppressed. This removes overlapping false positives and produces clean, accurate bee counts per frame.

Model Comparison

4 Deep Learning Models
Tested Head-to-Head

All models were trained on the same Roboflow-annotated dataset with identical hyperparameters for a fair comparison.

YOLOv5
mAP@0.50.7324
mAP@0.5:0.950.3328
Precision76.68%
Recall67.59%

Solid performance with anchor-based detection. Good balance of speed and accuracy, though outperformed by YOLOv8 on this dataset.

🏆 Best
YOLOv8
mAP@0.50.85
mAP@0.5:0.950.42
Precision85%
Recall79.6%

Best overall performance. Anchor-free architecture with strong generalisation. Consistently achieves the highest scores across all four evaluation metrics on this dataset.

YOLOv11
mAP@0.50.70
mAP@0.5:0.950.322
Precision77.6%
Recall64.7%

Newer architecture but lower recall. Optimisations for general efficiency appear to compromise sensitivity for small, high-density objects like honeybees.

Faster R-CNN
mAP@0.50.4956
mAP@0.5:0.950.2145
Precision30.8%
Recall42.0%

Lowest performer. Two-stage architecture optimised for larger objects. High computational cost and slower convergence make it unsuitable for real-time small-object detection.

💡
Key Finding: Single-stage YOLO detectors significantly outperform two-stage detectors like Faster R-CNN for honeybee detection. YOLOv8 achieved the best mAP@0.5 of 0.85 — nearly 72% better than Faster R-CNN. Newer architecture does not always mean better results — YOLOv11 scored lower than both YOLOv5 and YOLOv8 on this small-object dataset.

Applications

Real-World Applications

Beyond bee counting — this system supports multiple domains of beekeeping and ecological research.

🏥

Colony Health Monitoring

Monitors changes in the number of honeybees to detect possible colony decline or losses. Continuous tracking enables early identification of issues before they become catastrophic.

🌸

Pollination Research

Analyzes honeybee activity in farming areas to understand their role in pollination — providing data-driven insights for agricultural planning and sustainable farming practices.

🍯

Honey Production Optimization

Identifies the most productive hives by tracking activity levels, helping beekeepers improve honey yield and allocate resources more effectively across their apiaries.

📡

Automated Hive Monitoring

Uses AI technology to track bee population in real time, providing continuous hive observation without the need for manual intrusion — reducing stress on the colony.

Future Work

What's Next

Planned enhancements to evolve BeeVision into a fully autonomous smart beekeeping platform.

📹

Live Video Stream

Integrate webcam or IP camera feeds using OpenCV to perform frame-by-frame inference in real time — converting from offline analysis to continuous live hive monitoring.

🖥️

Edge Device Deployment

Deploy the trained model on Raspberry Pi or NVIDIA Jetson devices placed directly at hive entrances. Model quantization and pruning will ensure efficient performance on limited hardware.

📊

Multi-Hive Dashboard

A centralized dashboard supporting multiple simultaneous live camera feeds — displaying hive-specific statistics, activity trends, and historical data for commercial apiaries managing large numbers of hives.
